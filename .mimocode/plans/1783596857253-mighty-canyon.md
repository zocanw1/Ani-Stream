# AniStream Design Upgrade: Anime Aesthetic Bold

## Overview

Upgrade menyeluruh desain AniStream dari "Cinematic Focus" (dark Netflix-style) menjadi **Anime Aesthetic Bold** — vibrant, eye-catching, dengan gradient anime-style, glow effects, micro-interactions, dan scroll animations. Semua halaman di-upgrade sekaligus.

---

## Phase 1: Design System & CSS Foundation

### 1.1 New Color Palette (globals.css `:root`)

Ganti seluruh CSS variables dengan palet anime yang vibrant:

```
--primary: #ff2d7b        (Hot Pink / Sakura)
--primary-glow: #ff2d7b66 (Pink glow)
--secondary: #7c3aed       (Electric Purple)
--secondary-glow: #7c3aed55
--accent: #06d6a0          (Mint / Cyan)
--accent-glow: #06d6a044
--gold: #fbbf24            (Gold star rating)
--neon-blue: #38bdf8       (Neon Sky)
--neon-pink: #f472b6       (Neon Sakura)
--bg-deep: #0a0a12         (Deep space black)
--bg-surface: #12121e      (Card surface)
--bg-elevated: #1a1a2e     (Elevated surface)
--bg-glass: rgba(18,18,30,0.7) (Glassmorphism)
--border: rgba(255,255,255,0.08)
--border-glow: rgba(255,45,123,0.3)
--text-primary: #f0f0f5
--text-secondary: #9ca3af
--text-dim: #6b7280
```

### 1.2 Typography Upgrade

- **Display**: Geist (tetap, tapi tambah `font-black` weight)
- **Body**: Nunito (tetap)
- Tambah `--font-accent` untuk heading spesial (opsional: gunakan Geist untuk semua heading)
- Ukuran: pertahankan `clamp()` responsive, tapi sesuaikan line-height

### 1.3 New Animation System (globals.css)

Tambah CSS animations baru:

```css
/* Scroll-triggered fade-in */
@keyframes fadeUp { from { opacity:0; transform:translateY(30px) } to { opacity:1; transform:translateY(0) } }
@keyframes fadeLeft { from { opacity:0; transform:translateX(-30px) } to { opacity:1; transform:translateX(0) } }
@keyframes fadeRight { from { opacity:0; transform:translateX(30px) } to { opacity:1; transform:translateX(0) } }
@keyframes scaleIn { from { opacity:0; transform:scale(0.9) } to { opacity:1; transform:scale(1) } }
@keyframes glow-pulse { 0%,100% { box-shadow: 0 0 20px var(--primary-glow) } 50% { box-shadow: 0 0 40px var(--primary-glow), 0 0 60px var(--secondary-glow) } }
@keyframes float { 0%,100% { transform:translateY(0) } 50% { transform:translateY(-8px) } }
@keyframes shimmer-anime { 0% { background-position: -200% 0 } 100% { background-position: 200% 0 } }
@keyframes border-glow { 0%,100% { border-color: var(--primary) } 50% { border-color: var(--secondary) } }
@keyframes gradient-shift { 0% { background-position: 0% 50% } 50% { background-position: 100% 50% } 100% { background-position: 0% 50% } }
```

### 1.4 New CSS Utility Classes

```css
.glow-card { /* Card dengan glow effect saat hover */ }
.glow-border { /* Border yang berubah glow */ }
.anime-gradient { /* Background gradient anime-style */ }

```

Update semua CSS component styles:

## Design Principles

1. **Konsisten**: Satu palet warna, satu gaya glassmorphism, satu set animasi
2. **Vibrant tapi tidak norak**: Pink + purple sebagai primary, cyan sebagai accent
3. **Depth**: Glassmorphism, gradient layers, glow effects untuk visual depth
4. **Interactive**: Hover micro-interactions, scroll animations, smooth transitions
5. **Anime feel**: Gradient yang terinspirasi anime, glow effects, bold typography
6. **Performance**: Gunakan CSS-only animations (transform, opacity) untuk 60fps
